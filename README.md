# Fresh Produce Supply Chain Analytics

## Project Overview
This portfolio project explores supply chain operations for fresh fruits and vegetables using simulated practice data.

The objective is to understand demand patterns, monitor inventory, identify stockout risks, and develop data-driven recommendations to help reduce waste.

## Business Objectives
- Analyze product-wise demand and inventory levels.
- Understand safety stock and reorder point calculations.
- Monitor stock availability and potential overstock risks.
- Explore methods to reduce fresh produce wastage.
- Present key insights through an Excel dashboard.

## Tools Used
- Microsoft Excel
- Data Analysis
- Inventory Management
- Supply Chain KPIs
- Data Visualization

## Key Metrics
- Total Demand
- Opening and Closing Inventory
- Safety Stock
- Reorder Point
- Stockout Risk
- Inventory Wastage, if data is available

## Expected Deliverables
- Cleaned and analyzed dataset
- Excel dashboard
- Business findings and recommendations
- Project report

## Data Disclaimer
This is an independent portfolio project based on simulated practice data. It does not use Fambo's confidential or internal company data and is not an official Fambo project.
